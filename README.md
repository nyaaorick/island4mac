# island4mac

A macOS menu bar app that turns the MacBook notch into a "Dynamic Island": now playing with lyrics, coding-agent progress (Claude Code, Codex, ZCode), clipboard history and a drag-and-drop file shelf.

This project is a fork of https://github.com/RayTracingON/mac-dynamic-island.git

It is also based on [boring.notch](https://github.com/TheBoredTeam/boring.notch).

## Run it

Double-click `Launch.command` in Finder. It builds the app into `build/` and opens it. Requires macOS 26.0 or later and Xcode.

See `CLAUDE.md` for build and test commands and an overview of the code.
