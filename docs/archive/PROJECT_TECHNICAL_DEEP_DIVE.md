## 1. 核心架构：超越普通悬浮窗 (Core Architecture)

Mac灵动岛并不是一个简单的 "Always On Top" 窗口，而是一个结合了 **System Integrity**、**FSM (有限状态机)** 和 **Event-Driven (事件驱动)** 的系统级应用。

### A. 窗口管理 (The Window Engine)

**文件**: `Controllers/OverlayWindowController.swift`

这是一个从零构建的 `NSPanel` 容器，旨在模拟系统级 UI 行为。
*   **坐标系锁定**: 摒弃了左下角坐标系，采用 `screenFrame.maxY - targetSize.height` 算法。无论您的屏幕分辨率如何变化，它都会像钉子一样死死吸附在物理刘海或菜单栏的正下方。
*   **层级霸权**: 窗口级别设置为 `.screenSaver` (Level 1000+)。这意味着即使您开启了全屏游戏、观看 Netflix 或运行 Keynote 演示，灵动岛依然会浮在最上层。
*   **输入穿透 (Pass-Through)**:
    *   在 **Idle/Armed (紧凑)** 状态下，窗口的大部分区域是“透明”的，允许鼠标穿透点击背后的应用。
    *   在 **Active (展开)** 状态下，它会捕获所有交互事件。

### B. 交互中枢 (The Brain)

**文件**: `Coordination/InteractionCoordinator.swift`

这是一个严密的**有限状态机 (Finite State Machine)**，管理着应用的所有生命周期。它不仅仅是响应点击，而是管理着“确定的状态流转”。

*   **四大状态**:
    1.  **Idle (静止)**: 紧凑模式，仅显示核心信息。
    2.  **Armed (悬停预备)**: 鼠标悬停时轻微放大，提示用户可交互。
    3.  **Active (活跃)**: 完全展开，显示详细控制（音乐、剪贴板等）。
    4.  **Pinned (钉住)**: 用户强制固定，不会自动收起。
*   **防抖与安全**: 内置 Debounce 机制，防止鼠标快速划过导致 UI 抽搐（Jitter Protection）。

## 3. 物理引擎与动效 (Animation Physics)

**文件**: `Animations/BoringAnimationPhysics.swift`

我们的动画不仅仅是 `easeInEaseOut`，而是基于高精度弹簧物理模拟。

*   **Squishy Physics (果冻效果)**:
    *   当您拖拽灵动岛时，它不会生硬地移动，而是会像果冻一样产生微小的形变 (Scale 1.0 -> 1.05)。
    *   核心参数: `Response: 0.38`, `Damping: 0.8`。这组参数是从 Boring Notch 逆向分析得出的“黄金手感”数据。
*   **Snap-Back (回弹)**: 释放鼠标时，它会以临界阻尼 (Critical Damping) 迅速且无振荡地回到原位。

## 4. 全局状态管理 (Single Source of Truth)

**文件**: `State/AppState.swift`

这是整个应用的**心脏**。
